# История изменений

## 0.1.5

- движок zapret заработал: в пакет добавлен недостающий cygwin1.dll, без него winws не стартовал в принципе (код 3221225781 в журнале)
- самопроверка и скрипты verify-cores контролируют теперь и этот файл

## 0.1.4

- код «DLL не найдена» в журнале теперь сразу подсказывает распаковать архив заново, а не пугает числом

## 0.1.3

- журнал показывает код выхода движка: видно, сам он вышел с ошибкой или его убили снаружи

## 0.1.2

- приложение само перезапрашивает права администратора через UAC (без прав движки не могут поднять драйвер)
- если движок умирает молча даже с правами, журнал намекает на антивирус
- самопроверка заодно проверяет payload-файлы стратегий
- сборка на GitHub теперь ломается, если в exe не вшились манифест или версия

## 0.1.1

- исправлена пустая версия в шапке окна в релизной сборке
- журнал сразу пишет, если движок умирает при старте
- закрытие окна выключает движки, в фоне ничего не висит
- README: прямая ссылка на скачивание и подсказка не путать релиз с архивом исходников

## 0.1.0

- первая публикация
- тёмное окно с одной кнопкой и журналом
- 4 стратегии на zapret + запасной режим GoodbyeDPI
- режим «Авто»: перебор стратегий с реальной проверкой, открылся ли Discord
- обход только для списка доменов Discord, голос по UDP в комплекте
- автозапуск с Windows
- проверка контрольных сумм движков
- режим без окна для командной строки
