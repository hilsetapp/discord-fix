# История изменений

## 0.1.5 - движку не хватало файла

- в пакет движка zapret добавлен недостающий cygwin1.dll: без него winws не стартовал вообще (в журнале был код 3221225781). Спасибо первому пользователю за терпение с диагностикой
- самопроверка и скрипты verify-cores теперь контролируют и этот файл

## 0.1.4 - журнал понятнее про ошибки движка

- коды выхода движка переведены на человеческий: «не найдена DLL» теперь сразу подсказывает распаковать архив заново, а не пугает числом

## 0.1.3 - журнал показывает код выхода движка

- по журналу теперь видно, с каким кодом завершился движок: сам с ошибкой или его убили (антивирус, Smart App Control)

## 0.1.2 - права администратора точно есть

- приложение само перезапрашивает права администратора через UAC (в 0.1.1 манифест не добрался до сборки, из-за этого движки умирали мгновенно)
- если движок умер молча и с правами - журнал честно намекает на антивирус
- самопроверка заодно смотрит, что payload-файлы стратегий на месте
- сборка на GitHub теперь ломается, если в exe не вшились манифест или версия

## 0.1.1 - фикс первого запуска

- приложение само просит права администратора при старте (без них движки не могли поднять драйвер, из-за этого «не пробивалась» ни одна стратегия)
- ранняя смерть движка сразу видна в журнале с понятной подсказкой
- в релизной сборке снова показывается номер версии в шапке
- закрытие окна гасит движки, ничего не висит в фоне
- README: жирная прямая ссылка на скачивание и подсказка не путать релиз с архивом исходников

## 0.1.0 - первая публикация

- тёмное окно с одной кнопкой и журналом
- 4 стратегии на zapret + запасной режим GoodbyeDPI
- режим «Авто»: перебор стратегий с реальной проверкой, открылся ли Discord
- обход только для списка доменов Discord, голос по UDP в комплекте
- автозапуск с Windows по галочке
- `-selftest` с проверкой контрольных сумм движков
- режим без окна: `-check`, `-run`
